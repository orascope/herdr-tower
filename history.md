# herdr-tower history

What each release changed, oldest first. The README describes the current version.

- **v0.1.0**: the first release — herdr only, written in Rust. 2026-09-11.
- **v0.1.x → v0.1.14**: the dock in herdr's sidebar that reopens itself, the resident supervisor, idle continuation loops whose pauses lift themselves, `wt drive` and the `TEST00.SH` live smoke tests. 2026-09-12 – 2026-09-21.
- **v0.15.0**: the tool is named `herdr-tower`, with no backward compatibility; the TITLE column; the dock is `🗼 herdr-tower 🗼`; the pre-push gate. 2026-09-21.
- **v0.15.1**: no compatibility of any kind — herdr 0.9.0 is required, and the older herdr servers, older record and lease shapes and old metadata ids are gone. 2026-09-21.
- **v0.16.0**: major architectural cleanup — `main.rs` monolithic dispatch split into modular submodules (`rust/cli/src/cmd/`), raw extern C FFI replaced with safe `libc` bindings, unified structured `CliError` replacing opaque boxed errors. 2026-09-22.
- **v0.16.1**: fix dock workspace infinite creation storm caused by shell startup (`path_helper`, `.zshrc`) being treated as non-idle; cleanly close unadopted loser candidate workspaces. 2026-09-22.
- **v0.16.2**: always expose TITLE and TASK columns side-by-side on all widths (removing the 144-column cutoff); TITLE displays dynamic terminal pane title, TASK displays actual work prompt; add PANE coordinate column (`w1:p2`). 2026-09-22.
- **v0.17.0**: a SID column (eight characters of the session ID — the tail for codex's time-ordered IDs — from 140 columns) and the whole session ID in the preview heading; TITLE puts a `wt new` worker's generated name behind its terminal title; a click on the key guide presses that key; the supervisor keeps an event log (`supervisor.log`); the `mcp-serve` handshake fix; codex context read incrementally (the tower's memory went from ~100 MB to a few) and each frame laid out once; shared dependencies named once in the workspace. 2026-09-22.
- **v0.17.1**: the key guide wraps on a narrow screen instead of losing its last keys; `info` and `resume` take a session id (whole, or the SID column's eight characters — `resume` only for a stopped record); the supervisor logs a failed pass and tries again rather than exiting, and notes a predecessor that stopped without a word; `browser mcp-serve` checks and starts the browser off its relay loop, so other replies keep flowing, and no longer hangs on a refused call; property tests of the layout at every width. 2026-09-22.
- **v0.18.0**: scheduled messages — `herdr-tower schedule` and the tower's `T` send a message at a set time, once, daily or on weekdays, to one session, a workspace or every handoff folder, waiting up to 30 minutes for a busy agent; the supervisor delivers them at most once per pane and occurrence, a scheduled close stops the idle loop, and `close`/`wake` presets cover the evening wrap-up and the morning resume; `p`, `o` and `u` leave the key guide (they still work); date, time and offset parsing refuses signs and non-ASCII; four-strategy tests across this release's changes. 2026-09-22.
- **v0.19.0**: the sibling-tool integrations are gone — no coach usage screen (`u`), no usage blocks or limit pings on the Discord card, no claude statusline ctx, no MultiAgent task line (#22); tmux handling is gone — no `TMUX_PANE` guards, no tmux-run bot units in the wiring, no `%N` pane IDs; every Go and tmux mention is out of the code and docs, the Go-era captures and plans deleted, and the recorded test inputs moved to `rust/expected/`. 2026-09-22.
- **v0.19.1**: the TITLE column reads `tab › title` — the herdr tab the pane is in, then its title, cut before the tab is — and a blank row keeps the list apart from the preview, so a selected last row no longer runs into it. 2026-09-22.
- **v0.19.2**: the row between the list and the preview is a yellow dot line instead of blank, so a selected last row and the preview's grey never read as one bar. 2026-09-22.
- **v0.19.3**: holds up at 100 sessions — the scanner writes a record only when it changed (an unchanged 100-agent pass went from ~550 ms to ~10 ms, and hooks no longer wait on a pass full of flushes); the supervisor logs slow passes once; a flaky auto-preview lock fixed. 2026-09-22.
- **v0.19.4**: nothing on disk grows without a bound — the supervisor sweeps hourly: picks and screenshots past 7 days or 200 MB, tower lock files unused for a week, loop instructions for conversations that are gone; `daemon.log` is cut to its last 64 KiB past 1 MiB. 2026-09-22.
- **v0.19.5**: copy from the preview — drag to select (drawn reversed, copied on release), click the heading's session ID to copy the whole ID; a second yellow dot line between the preview and the key guide; the TITLE separator loses its spaces (`tab›title`). 2026-09-22.
- **v0.19.6**: fixes — the dock reads 🗼 HERDR-TOWER 🗼 and a herdr restart no longer leaves it with a second tab; emoji like ❤️ are cut and selected as two columns; `quote` writes only TOML escapes; a long tab beside a short title is drawn whole; `pane_id` falls back correctly for named backends; the slow-pass log says how much was the store lock. 2026-09-23.
- **v0.19.7**: fixes, and one width rule — text is measured the way the screen draws it everywhere (a line of Arabic lam-alef no longer overflows its cell, a halfwidth katakana sound mark counts its column, and the editor's caret cannot be pushed off the right edge); a launcher that was commented out is read as commented out, by the grammar of the unit it is in; `--session` is no longer taken for a spawn verb; the dock's tab name is checked on its own, so a failed relabel no longer costs a second tab after a restart; a failed `tab.list` keeps each record's tab label instead of blanking every one; a hook stops spending its whole patience on a lock error that retrying cannot fix; every supervisor pass is counted, including one that ends early; a short codex rollout's header is read once instead of every pass. 2026-09-23.

The colour was measured rather than picked: pink and violet were both shipped and taken back, each of them nearer the loop badge's own pink than anything else in the palette. 2026-09-23.
- **v0.19.9**: opencode is supervised. herdr has been naming its panes all along, but the scan fold answered `None` for any kind outside claude/codex/gemini/agy, so the pane was skipped and no row was ever written — the agent ran outside the tower. It is now followed everywhere a supervised kind is consulted: `wake-all`/`close-all` and schedules reach it, the AGENT column is eight wide so its rows stop shifting the ones after them, a long hookless turn is no longer blamed on a hook that cannot exist (`WORK?`), it ranks beside the known kinds rather than with the unknown ones, and `restore` brings it back as a fresh `opencode` in the folder it died in — no resume, since no conversation ID has ever come from it. The preview panel sits on dark slate teal (`#1f303a`, was `#464646` grey), so the text drawn on it gains contrast instead of losing it. 2026-09-23.
- **v0.20.0**: every row says more, and the tower says when it is not being heard. claude rows show their model and context share, read from the session transcript (`~`, the window being assumed; `(1M)` when it is the 1M one). opencode gets a hook — the plugin `init` installs — so its rows carry the task, the question, the session ID (`resume` runs `opencode --session`), the model, a measured context share and ERR; `wt new --agent opencode` works. `herdr-tower doctor` checks that every hook, the opencode plugin and the service still point at a real binary — and `init` now writes the path an upgrade keeps (on Linux the old one resolved to Homebrew's versioned folder, which `brew upgrade` deletes). A WAIT nobody answers is announced once more after 15 minutes (`wait_renotify`). `herdr-tower report` says what each session did in a window — turns, work, time waiting on you and on what — from a new transition journal. Fixes: a phantom turn counted at every opencode stop (herdr reports `done` half a second after the hook; a turn start now waits out a 10s grace), a codex compaction no longer drops its turn to IDLE, and a sandbox store no longer posts to the user's Discord. 2026-09-24.
- **v0.21.0**: the tower can be driven from a phone. `herdr-tower mcp` runs a remote MCP server — a claude.ai custom connector, and so the Claude phone app, reaches it through a Tailscale Funnel ([Driving it from a phone](docs/remote-mcp.md)). Every connection is approved with a six-digit code from `herdr-tower mcp pair` (OAuth 2.1 with PKCE, tokens kept only as hashes) and can read the agents, their screens, `report`, schedules and loops. A connection whose "send instructions" box was ticked can also type into an agent (`send_prompt`, never into a shell, never into a dialog), wait for it, answer a dialog only for the screen it read (`answer_prompt`), and run **any herdr-tower command line** (`tower`, nothing held back). Every such act is recorded (`mcp-audit.jsonl`, a "remote actions" section in `report`) and posted to the notification channel; `mcp on`/`off`, `grants`, `revoke` and a `doctor` section manage it. Also: `daemon install` waits for launchd to let go of the old service before loading the new one, and the README says that codex needs its hooks trusted after `init`. 2026-09-24.
- **v0.21.1**: every setting can be changed without opening the file, and so over MCP. `herdr-tower config get [key] [--reveal] | set <key> <value> | unset <key> | keys | path` sets only known settings, parses each by its type, and writes nothing that would not load — a file the tower cannot read is replaced by the defaults at runtime, webhooks included, so a typo never reaches it. Webhook URLs stay hidden unless `--reveal`. Through the MCP `tower` tool the same command works from a phone (`["config","set","wait_renotify","off"]`). Also: property, cross-check and round-trip tests for the remote MCP server (`shell_words` read back by a real `sh`, the screen token's invariants, form encoding, rate limits). 2026-09-24.
- **v0.21.2**: a reader that leaves early no longer breaks a command. `herdr-tower status | head -1` (or any command whose output is cut short) used to panic (`failed printing to stdout: Broken pipe`) or print `herdr-tower: Broken pipe (os error 32)`; it now ends quietly with exit 141, the status a shell reports for a process SIGPIPE ended. SIGPIPE itself stays ignored, so the supervisor and the MCP server still get an error, not a death, from a socket the other side closed. 2026-09-24.
- **v0.22.0**: the remote MCP server speaks the stateless revision 2026-07-28 and holds up to a stranger. A client that sends `_meta` with each request is served without a handshake (`server/discover`, the mirrored `MCP-Protocol-Version`/`Mcp-Method`/`Mcp-Name` headers checked against the body, `resultType` and cache hints on results), while a client that opens with `initialize` is served exactly as before; the approval redirect carries `iss` (RFC 9207). Fixes found by the bug tracker: a handful of connections that sent a `Content-Length` and then nothing left every route unanswered — tiny_http is gone, and a request must now arrive whole within 10 seconds (#116); another client's sign-in could push your approval page out (#119); a revoked token finished what it had in flight, trimming the audit log left it world-readable, and busy tools blocked sign-in (#117); a pairing code now belongs to one approval page, with no global lockout (#111); every act is audited and the audit log is safe under concurrency (#110); a `tower` run leaves no threads or descriptors behind (#109); a huge `report` window is an error and a panicking handler gives its slot back (#108). 2026-09-24.
- **v0.23.0**: plan usage, and a guard that stops the tower from spending it. `herdr-tower usage` (and a `📊 USAGE-GUARD` tab the supervisor keeps right of the dock's) shows claude's and codex's plan, how much of each five-hour and seven-day window is used, as bars coloured green, orange and red, and when each resets — with a calendar of the next eight days. claude is read from the endpoint its `/usage` reads, codex live from `codex app-server` (a reached limit says so). The usage guard keeps a floor per AI and window (5% steps, 25% unless set; drag the slider above a bar, or `config set usage_guard_<ai>_<5h|7d>`): below it the tower holds its idle-loop and scheduled sends to that AI, asks the agents working then to wrap up, tells them when the hold ends, and tells you of each hold, release and floor change. Every message the tower sends an agent by default is now English (the wake and close instructions, the idle-loop header); what you type goes out as you wrote it. Fixes: `schedule rm` checks every id before removing anything (#124); concurrent `config set`s keep every edit and never tear `config.json` (#123); idle-loop leases survive `all close`, a failed send and a stale `done` token (#127–#129). 2026-09-24.

A loaded machine no longer turns slow into failed: `daemon start` leaves a supervisor whose heartbeat is behind but whose process lives alone for five minutes instead of restarting it mid-pass; a send whose reply from herdr is lost after the text went out counts as sent, so a scheduled message is no longer typed twice and an idle loop is no longer paused; and the scanner writes a record back only over the copy it read, so a hook that wrote unlocked during a long pass keeps its state, task and question. 2026-10-23.
- **v0.60.1**: `wt new` starts its worker on a loaded machine. It asked herdr to start the agent 13–63ms after the new tab's shell was spawned and gave up on the first "agent target pane … is not an available shell"; the shell needs about 100ms to reach its prompt under load, so nine spawns in ten failed. It now waits that refusal out for up to ten seconds, as `herdr-tower open` already did. 2026-10-24.
- **v0.61.0**: the preview folds to a band, like a machine's. Its heading starts with `▼`; a click folds it to that one line (`▶`), which captures nothing, and a click on the line opens it again at the height it had. A list too long for the automatic split now shows the preview folded at the foot instead of not at all — a click opens it at half the screen, a drag pulls it up to any height. `[` at the smallest height folds it, `]` from the band opens it to what it was, `=` goes back to the automatic split. 2026-10-24.
